# 茅台年报 RAG 项目路线图

> 目标：基于贵州茅台 2022–2025 年年报（4 份 PDF，共 556 页）搭建一个可评测的
> 知识库问答系统，最终产出 = 可运行的代码 + 评测对比表 + GitHub README。

## 数据

- 来源：巨潮资讯网（cninfo.com.cn）公开披露，中文完整版年报
- 位置：`data/raw_pdfs/moutai_{2022,2023,2024,2025}.pdf`
- 已验证：pypdf 可直接提取文本（非扫描件，无需 OCR）
- 后续困难语料（第 5 阶段可选）：招商银行 600036 年报

## 目录约定

```
data/raw_pdfs/      原始 PDF（只读，不改）
data/extracted/     提取出的文本
data/gold/          黄金问答集 questions.jsonl
data/db/            向量库（Chroma 持久化）
scripts/            一次性工具脚本（下载、提取、评测）
src/                项目主体代码
```

## 阶段 1：最小 RAG 跑通

1. 建虚拟环境，安装：chromadb、LLM SDK、embedding（本地 bge-small-zh）
2. `pypdf` 逐页提取文本 → `data/extracted/`
3. 切块：约 500 字/块，重叠 100 字
4. 向量化 → 存入 Chroma
5. `ask.py`：检索 top5 → 拼 prompt → LLM 生成，答案必须带出处（年份+页码）
6. 验收：问"2024 年茅台营业总收入是多少"，答对且出处正确

## 阶段 2：黄金问答集（约 50 题）

- 30 道简单事实题（单块能答）
- 10 道跨页/跨表题（如分渠道营收表）
- 5 道跨文档题（如 2022 vs 2025 经销商数量变化）
- 5 道无答案题（年报里没有的，考察"承认不知道"）
- 格式：`data/gold/questions.jsonl`，字段：question / gold_answer / source / type
- 出题方式：AI 起草原稿 → 人工核对答案和页码

## 阶段 3：评测基线

- 用 ragas 跑四项指标：忠实度（不胡编）、答案相关性、检索精确率、检索召回率
- 得到基线分数，作为后续所有优化的对照组

## 阶段 4：优化实验（每个实验跑一遍评测，出对比表）

- 实验 A：切块策略（固定 500 字 vs 按标题结构切块 vs 父子块）
- 实验 B：混合检索（向量 + BM25 关键词双路召回）
- 实验 C：加 bge-reranker 精排
- 产出：一张"策略 × 指标"对比表 = README 核心素材

## 阶段 5：界面与发布（可选加分项）

- Streamlit 问答页面，显示答案 + 引用出处
- README：架构图、评测表、典型 badcase 分析
- 可选：加入招商银行年报，做"困难语料"对比实验
