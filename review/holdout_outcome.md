# 留出集评测结果（2026-11-11）

## 为什么做

调参集 50 题的 hit@5 86% 中，融合权重 α=0.5 是在同一套题上扫出来的，
存在"考前知道考题"的溢价。本轮造一批**从未参与调参**的题冻结后复跑，
检验 86% 能否外推。

## 方法

- **150 题**：90 事实 / 30 跨页 / 15 跨年 / 15 无答案，配比镜像调参集。
- **页级隔离**：调参集 50 题用过的 32 个出处页全部排除，留出页从其余
  约 510 个内容页中选取。
- **出题**：Qoder agent 对话内直接读原文页写题，零 API 成本；数字一律
  按原文 verbatim（不做亿元换算）。
- **客观校验**（`scripts/build_holdout.py --check`，13 项 pytest 先行）：
  答案每个数字须在所标页原文出现（去空白口径，沿用 verify_gold_answers）、
  与调参集归一化查重 + 二元组 Jaccard≥0.8 近似查重、页级隔离、题型配比。
  **150 题一次通过，problems=0**。
- **冻结**：`data/gold/holdout_manifest.json`，
  sha256 `2ec04827fb5b576e…`，2026-11-11。此后不在其上调整任何参数。
- **评测**：`scripts/eval_holdout.py`，与 CI 门禁同一套 `run_eval` +
  `get_search()` 生产管线，纯本地零成本。逐题明细
  `results/holdout_retrieval.json`。

## 结果

| 题型 | 调参 50 题 | 留出 150 题 | 差值 |
|---|---|---|---|
| overall | 86.00% | **77.33%** | -8.67pp |
| fact | 90.00% | 83.33% | -6.67pp |
| cross_page | 90.00% | 90.00% | 0 |
| cross_year | 80.00% | 80.00% | 0 |
| no_answer | 60.00% | 13.33% | -46.67pp |

只看 135 道有答案题：调参 88.89%（40/45）→ 留出 **84.44%**（114/135），
-4.4pp。all_gold_hit@5（严格口径，覆盖全部 gold 页）留出集 67.33%。

## 34 道未命中题的归因

**no_answer 13 题——口径伪影，不是检索退化。** 无答案题的 gold 是"相关
话题页"，但相关页不唯一：id236（五粮液净利润）检索返回的是利润表页
（2024P64/P66），比我标的渠道收入页（P17）更相关；id248（生肖酒产量）
返回产能页 P14 而非我标的 P15。调参集 60% 的 no_answer 命中是 5 题小样本
加 gold 页恰好对齐的结果。**无答案题的检索命中率不宜作为质量指标**，
其真正指标是答案层的拒答正确率（调参集 100%）。

**fact 15 题——四类：**
1. **头条指标多页出现、gold 只标一页**（约 7 题）：id132/197（营业收入
   在主要会计数据页与利润表附注页都有）、id115/202（存货/货币资金在
   资产负债分析页与报表附注页都有）、id172（技改投资在投资状况节 P18
   与在建工程附注 P99 都有）。检索返回的附注页往往也含正确答案数字，
   单页 gold 把这类判成 MISS，**真实检索质量被低估**。
2. **相邻页边界**（约 4 题）：id150/151/210（分红内容跨 P33–P34，返回
   P33）、id120（员工情况跨 P30–P31）、id206（渠道数据 P17–P18）。
3. **年份混合**（1 题）：id147（"2023年报提出的2024年目标"，返回 2024
   报告页）——真实难点，与审计 M5 年份范围问题同类。
4. **报表口径**（1 题）：id180（资产总计，返回母公司资产负债表页而非
   合并页）。

**cross_page 3 题**：id129（增持+贵州银行，年份混合）、id187（技改投资
多页）、id215（分红多页）。**cross_year 3 题**：id227/228/232，均为
"资产负债表页 vs 财务分析页"的 gold 选择歧义加多年份检索。

## 结论

1. **86% 含约 9pp 调参溢价**；可外推的检索水平约 77%（有答案题 84%）。
   跨页/跨年题零回退，说明结构化检索改进是真实的。
2. 单页 gold 对"答案在多个页面出现"的头条指标系统性偏严，这是留出集
   暴露的**评测口径问题**，不是管线问题。本轮不事后放宽口径（放了就是
   新一轮调参污染），记录在案。
3. no_answer 的检索命中口径作废，拒答质量留待答案层评测。

## 答案层留出评测（2026-11-11，DeepSeek-Flash）

150 题全跑通，**0 个 API 错误**；路由 56 agent / 94 direct。复现命令
（本机 Windows 注册表 ProxyOverride 含 `[::1]`，会让 httpx trust_env 崩溃，
须用 `NO_PROXY` 覆盖）：

```bash
NO_PROXY="localhost,127.0.0.1" RAG_BASE_URL=https://api.deepseek.com/v1 \
RAG_MODEL=deepseek-flash RAG_API_KEY=<.env 里的 Key> \
.venv/Scripts/python.exe scripts/evaluate_answers.py --router \
  --gold data/gold/holdout.jsonl --name holdout_cloud
```

### 拒答：最硬的指标，3 倍样本复现

- 无答案题拒答正确率 **100%（15/15）**，复现调参集 100%（5/5），样本扩到
  3 倍仍零编造。
- 假拒答率 **3.7%（5/135）**，优于调参集 8.9%。

### 完整答案率：发现并修正了一个打分口径偏差

原始打分 67.41%。但 `evaluate_answers.gold_numbers` 对 gold_answer **全文**
抽数字，把出处引文里的表格其他数字（毛利率题引文带了营收/成本）、出处
页码 P12 里的 "12" 都当成"必须出现在答案里的数字"——答案明明答对却判错
（如 id106 答 94.19% 完全正确，却因引文里的营收数字被判 3/5）。

修正：`clean_answer` 先剥出处标注再抽数字，并改成**按括号配平扫描**以
处理引文里嵌套的（1）/（含基础酒）小括号（旧正则遇嵌套整段匹配失败）。
对调参集与留出集**同样**重打，双口径并列，不单独美化任何一边
（`scripts/rescore_holdout_answers.py`，零 API）：

| 题型 | 调参 旧→修正 | 留出 旧→修正 |
|---|---|---|
| 有答案题 overall | 57.78% → 66.67% | 67.41% → **91.11%** |
| fact | 56.67% → 70.00% | 65.56% → 92.22% |
| cross_page | 50.00% → 50.00% | 70.00% → 83.33% |
| cross_year | 80.00% → 80.00% | 73.33% → **100%** |

修正口径下留出 91.1% **高于**调参 66.7%：答案层不仅没回退，调参集数字
反而偏保守（旧口径偏差 + 调参题更难/更歧义）。跨年题 15/15 全对。

### 修正口径下仍答错的 12 题归因

- **检索未送达（6 题）**：id146/151/153/172/187/215，与检索层 miss 同源
  （多页 gold / 相邻页 / 年份混合）。
- **合并 vs 母公司口径混淆（2 题）**：id169/170，模型取了母公司现金流量
  表/营收附注的数字，与合并口径 gold 差一点。
- **合计行假拒答（3 题）**：id175/191/219，单项答对但"合计"行模型说
  未披露而拒答。
- **分季度检索未送达（1 题）**：id214，全年答对、Q1 营收没检索到。
- **题目歧义（1 题，出题瑕疵）**：id177"最近三个会计年度"没锚定年份，
  模型取 2025 报告三年累计、gold 是 2024 报告。

### 答案层结论

1. **拒答 100% 在 3 倍样本上复现**——"查不到就明说"这条底线是真的。
2. 答案层可外推水平约 **91%（修正口径）**，瓶颈回到检索未送达与少数
   口径/合计行问题，**不是生成端编造**。
3. 打分口径偏差已修（剥出处 + 嵌套括号配平），双口径并列留档；未事后
   放宽命中判定，调参集同步重打。

## 下一步建议

- **检索层**：头条指标 gold 标多页（或按"答案数字出现页"判命中）；相邻页
  按页去重；年份范围识别（审计 M5，"2022到2025年"漏中间年）。
- **答案层**：合计行假拒答（提示模型合计可能在表格末行）；合并 vs 母公司
  口径在提示里点明默认合并。
- **出题**：无年份锚点的"最近三年"类题须锚定年份（id177 教训）。
- **CI**：可加 holdout 检索复跑（纯本地免费），阈值另定；答案层留出评测
  约 0.5 元/次，按需手动跑。
- **打分器**：`evaluate_answers.gold_numbers` 的前向修正（剥出处）本轮只在
  离线重打里做了，是否改进生产打分器待定——改了历史数字口径会变。
